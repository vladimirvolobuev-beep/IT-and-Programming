# IT-and-Programming
Работы по дисциплине "Информационные технологии и программирование" в рамках программы "ТОП ИТ СТАРТ". Здесь собраны лабораторные и практические задания - для демонстрации освоения технологий и подходов к разработке. В репозитории отражён мой прогресс в изучении ИТ-инструментов и решении прикладных задач.
